# Influence Guard AI
Influence Guard AI

AI-Powered Influencer Fraud Detection & Creator Authenticity Analysis Platform

Influence Guard AI is a Streamlit-based platform that analyzes YouTube creator data to identify suspicious engagement patterns and estimate creator authenticity using data analysis and machine-learning techniques.

🚀 Features
🔍 YouTube channel analysis
🤖 AI-based fraud/anomaly detection
📊 Engagement and creator metrics analysis
🛡️ Suspicious creator identification
📈 Influence score calculation
👤 User authentication
🗄️ MySQL database integration
📋 Analysis history and reports
🎨 Interactive Streamlit dashboard
🛠️ Tech Stack
Technology	Purpose
Python	Core programming
Streamlit	Web application & UI
Pandas	Data processing
Scikit-learn	Machine learning / anomaly detection
MySQL	Database
MySQL Connector	Database connectivity
YouTube Data API v3	YouTube channel data
Joblib	ML model persistence
HTML/CSS	UI styling

🧠 How It Works

User logs into the application.
User enters a YouTube Channel URL or Channel ID.
The application retrieves publicly available channel information using YouTube Data API v3.
Creator metrics are processed and analyzed.
Engagement and growth-related indicators are calculated.
The system generates a fraud score and creator status.
Analysis results can be stored in the MySQL database.
Users can review their previous analyses and reports.
